# Hidden House Mod

## This will be the official guide to this mod because Modrinth isn't approved yet.

This mod adds tools to make hidden bases which I thought of and I will take suggestions for new blocks (github issues!!)

## The current blocks are:
- Hidden Block: When you place this block, you set a code. When you right-click the block you enter the code and if it is correct, it "opens" the block and when you step on it, it teleports you 2 blocks down from the block and locks the block again.
- Reverse Hidden Block: Same as Hidden Block, but teleports you 2 blocks up when its open and you right-click it.
